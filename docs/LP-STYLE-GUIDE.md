# Code Chips LP 共通スタイル仕様

更新日：2026年10月27日。今回のチャットで制作者が指定したスタイルの最新版です。
基準LPは「金塊を掘り出せ！」。商品情報・画像・文章・ページ構成ではなく、以下の見た目のルールを今後のCode Chips教材LPで再利用します。

## 必須ルール

| 対象 | 設定 |
| --- | --- |
| フォント | Noto Sans JPを先頭に指定。本文・見出し・ボタン・数字へ適用 |
| フォント読み込み | Google Fontsで400〜900の可変ウェイト。display=swap |
| h1・h2 | font-weight: 900 |
| --red | #F44336 |
| --green | #00754a |
| 濃緑のセクション背景 | #006241。共通CSSでは--green-darkとして定義 |
| .hero h1 span | color: var(--green) |
| .eyebrow | colorを指定しない。親要素から継承 |
| 旧--orangeの適用箇所 | var(--red)へ切り替える。ヒーロー強調とeyebrowは上記の最新指定を優先 |

900は擬似的な太字で済ませず、実際に読み込むフォントのウェイト範囲へ含めます。
`.classroom`の濃緑背景と、文字・枠線に使う`--green`は別の色です。
`.eyebrow`には`color: inherit`も足さず、個別セレクターやメディアクエリ内のcolor指定を取り除きます。明るい背景では通常文字色、濃い背景では親の明るい文字色を継承させます。

## 新しいLPに適用する

1. 共通仕様と `shared/lp-common.css` を新しいプロジェクトへコピーする。
2. 次のフォント読み込みをheadに入れる。
3. ベースCSS・コンポーネントCSSの後に共通CSSを読み込む。
4. ベース側の競合する色・フォント・ウェイト指定を整理する。特に`.hero h1`などの詳細度が高いルール、fontの一括指定、個別の`.eyebrow`、複数の`:root`を確認する。
5. 色や太さを変える場合は、そのLPでの制作者の最新指示を優先する。変更を共通仕様へ広げるのは、その意図が明確な場合に行う。

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400..900&amp;display=swap">
<link rel="stylesheet" href="./shared/lp-common.css">
```

共通CSSは、既存LPに重ねられるスタイル差分です。ページのレイアウトを一式定義するものではありません。現行の「金塊」LPは同じ設定を既存のCSSへ直接反映済みのため、共通ファイルを重複して読み込む必要はありません。
旧`--serif`の参照が残るLPへの互換用に、共通CSSでは`--serif: var(--sans)`も定義しています。新規実装は`--sans`を使います。

## 補助の見た目

- メインボタンは赤。ホバーは#d32f2f、影は#b71c1c。
- 英数字もNoto Sans JPを使う。旧Georgia・明朝体の指定を残さない。
- ヒーローのイラスト枠は、角丸20pxの一続きの枠を基準にする。アーチ枠・破線と画像内背景が重なって不自然な輪郭にならないよう確認する。
- ロゴや教材画面の画像内文字は、画像素材として扱う。Webフォント変更だけでは変わらない。
- 紙色・緑を基調とする配色、余白のある構成は基準LPを参考にする。画像・セクション構成・文字サイズは新しい教材と掲載内容に合わせて設計する。

## 確認すること

- PC・スマートフォンでフォントの読み込み、h1・h2の900、折り返し、横はみ出しを確認する。
- すべての`.eyebrow`について、表示色が親と一致することを確認する。
- リンク・ボタン・ミッションなど、そのページにある操作を確認する。
- 画像・CSS・JavaScriptは相対パスとし、サブディレクトリで確認する。

## 商品ごとに差し替えるもの

タイトル、説明文、画像、動画、価格、対象、利用条件、購入リンク、noteリンク、公開URL、canonical、OGP画像・URL、解析設定は商品ごとに確認する。
基準LPの「金塊」の文章・価格・ミッション数・リポジトリ・ローカルパス・公開先を、新しいLPへそのまま引き継がない。
GitHubへの保存と、本番サーバーへのアップロードは別作業として扱う。

## 別チャットで使う

保存した個人用テンプレート「Code Chips LP Style」を指定し、作りたい教材と資料を伝える。
この仕様とCSSはGitHub側にも保存するので、テンプレートが使えない環境ではこのファイルを参照先として渡す。
